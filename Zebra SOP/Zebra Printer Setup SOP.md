# Zebra Printer Setup SOP

**Printer:** Zebra ZD621R &nbsp;|&nbsp; **Ribbon:** 4.33" × 244' &nbsp;|&nbsp; **Connection:** Bluetooth &nbsp;|&nbsp; **Password:** `2957`

---

## 1. Power On

![Printer power on](Screenshot%202026-04-21%20at%2014-43-18%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. Plug in the power supply.
2. Hold the **⏻ power button** until the lights flash.
3. Screen should show **"Idle"** and the Status LED should be **solid green**.

---

## 2. Enable Bluetooth

![Bluetooth menu](Screenshot%202026-04-21%20at%2014-21-08%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Bluetooth settings](Screenshot%202026-04-21%20at%2014-22-20%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Bluetooth discovery on](Screenshot%202026-04-21%20at%2014-22-40%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. **Menu › Connection › Bluetooth**
2. Bluetooth → **On**
3. Discovery → **On**
4. Security Mode → **4**

---

## 3. Turn Off Ethernet & Wi-Fi

![Networking menu](Screenshot%202026-04-21%20at%2014-22-46%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![IP Protocol setting](Screenshot%202026-04-21%20at%2014-23-06%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. **Menu › Connection › Wired › Wired IP Protocol** → select **Permanent** (scroll to bottom)
2. **Menu › Connection › Wi-Fi › Wi-Fi IP Protocol** → select **Permanent** (scroll to bottom)

---

## 4. Set Password

![Set password](Screenshot%202026-04-21%20at%2014-23-48%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Password level](Screenshot%202026-04-21%20at%2014-23-56%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. **Menu › Settings › Set Password** → enter **2957** → tap ✔
2. Set **Password Level** → **All**
3. Confirm all settings show a 🔒 icon.

---

## 5. Install Ribbon

![Open printer](Screenshot%202026-04-21%20at%2014-24-05%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Ribbon holders](Screenshot%202026-04-21%20at%2014-24-26%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Ribbon path](Screenshot%202026-04-21%20at%2014-24-55%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Ribbon detail](Screenshot%202026-04-21%20at%2014-43-25%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. Pull the **yellow latches** on each side to open the printer.
2. Place ribbon roll on the **bottom dispenser** — feed ribbon **UNDER** the roll.
3. Pull the ribbon over the print edge and wrap it onto the **top dispenser** (tape if needed).
4. Turn the **top-left yellow knob** to tighten.
5. **Quick test:** Press a sticker onto the ribbon — ink should transfer. If not, flip the roll.

---

## 6. Install RFID Tag Roll

![Tag roll orientation](Screenshot%202026-04-21%20at%2014-25-35%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Feed through back](Screenshot%202026-04-21%20at%2014-25-41%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Media guides](Screenshot%202026-04-21%20at%2014-25-46%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Guides snug](Screenshot%202026-04-21%20at%2014-25-51%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Tag loading detail](Screenshot%202026-04-21%20at%2014-43-38%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Tag alignment](Screenshot%202026-04-21%20at%2014-43-44%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. Load the tag roll in the external holder — **HT holes on the LEFT**.
2. Feed tags through the **slot in the back** of the printer.
3. Thread through the **yellow media guides** and out the front.
4. Push the yellow guides **snug** against the tag edges.
5. Close the lid — press down until it **clicks**.

---

## 7. Calibrate

![Calibration buttons](Screenshot%202026-04-21%20at%2014-26-05%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Calibration running](Screenshot%202026-04-21%20at%2014-26-11%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Calibration detail](Screenshot%202026-04-21%20at%2014-43-54%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

**Do this after loading new ribbon or tags, or if the printer prints "VOID" or shows an RFID error.**

1. Close the printer lid.
2. Hold **⏸ Pause + ✖ Cancel** for **2 seconds**.
3. Wait for the printer to feed a few labels and return to **"Idle"**.

---

## 8. Pair with TC Handheld

![Pairing screen](Screenshot%202026-04-21%20at%2014-26-20%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Bluetooth MAC address on printer](Screenshot%202026-04-21%20at%2014-26-24%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Pairing complete](Screenshot%202026-04-21%20at%2014-26-29%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![Pairing detail](Screenshot%202026-04-21%20at%2014-44-29%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

1. On the printer screen, find the **Bluetooth MAC address** (under Printer Info).
2. On the TC device, open **IhmCandyCane** app.
3. Tap **☰ Menu › Store Tools › Scan, Validate, & Print**.
4. Enter the MAC address (use colons — e.g. `AC:3F:A4:12:5B:9E`).
5. Tap **Pair** — wait for **"Pairing complete ✔"**.

## Troubleshooting

### Status LEDs

![LED locations](Screenshot%202026-04-21%20at%2014-26-40%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

![LED meanings](Screenshot%202026-04-21%20at%2014-26-52%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

| LED | Green | Red | Amber/Blinking |
|---|---|---|---|
| Status | Ready | Error / media out / cover open | Printhead issue |
| Pause | — | — | Paused (amber) · Overheating (blink red) |
| Data | Data pending | — | Transferring (blink green) |
| Supplies | — | Media out | Ribbon out (blink red) |
| Network | Connected | Fault | Associating (blink) |

### Buttons

![Button layout](Screenshot%202026-04-21%20at%2014-27-05%20ZD421%20and%20ZD621%20Series%20Desktop%20Printers%20User%20Guide%20-%20zd421-zd621-ug-en.pdf.png)

| Button | Tap | Hold |
|---|---|---|
| ⏻ Power | Sleep | Hold 4–9s → Shutdown |
| ⏸ Pause | Pause/Resume | — |
| ▶ Feed | Feed one label | Keep advancing |
| ✖ Cancel | Cancel next (paused only) | Hold 2s → Cancel all |

### Common Fixes

| Problem | Fix |
|---|---|
| Prints "VOID" | Recalibrate (Step 7) |
| RFID not detected | Check tag alignment, recalibrate |
| Won't pair | Check Bluetooth is On + Discovery On (Step 2) |
| Red Status LED | Check media loaded, lid closed |
| Red Supplies LED | Replace ribbon or tag roll |
