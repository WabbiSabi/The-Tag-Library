Tagging Compliance in Pop-Ups

Current State

We have quite a few pop-up events coming up and all of our learnings from these events all closely align together: Example: PGA-AMEX - Site Survey

Staffing & Training Issues

1. Merchants lack time to extensively train associates
2. Associates are typically part-time with minimal investment in outcomes
3. Shift variations prevent consistent staffing
4. Cannot rely on same personnel throughout event day(s) should issues arise


Operational Constraints

1. Pre-launch periods are high-stress and chaotic for merchants
2. Tagging compliance becomes lowest priority during crunch time
3. Limited BOH space for on-site tag printing
4. Insufficient overhead capacity for printing and applying tags
5. Unpredictable inventory replenishment at random intervals


Food & Beverage Specific

1. Tags difficult to identify without titles
2. Need tidier dispensing method for printed tags on-site


MPV for 3P Implementation

*   Digital checklist
*   Photo upload requirement at 5 key checkpoints
*   Pre-launch EPC scans
*   Simple scoring rubric (manual calculation initially)
*   Vendor training video covering SOPs?


Resource Allocation Criteria

Tier 1:  High-Value/Complex Pop-Ups

* Full-time on-site (white glove service)
* Direct merchant support and compliance ownership

Inventory Unpredictability:

* Replenishment happens at random intervals with no advance notice 
* Merchandise quantities unknown until arrival at venue
* Multiple merchandise drops throughout event (not single delivery)
* Vendor cannot commit to final SKU list 48+ hours before event

Operational Constraints:

* Limited BOH space cannot accommodate pre-tagged merchandise storage 
* Merchant has no overhead capacity to manage pre-printed tags 
* Part-time associates with high turnover (cannot train on tag application) 
* High-stress pre-launch environment where tagging is lowest priority 

Event Characteristics:

* First-time venue with unknown conditions
* High-value event where compliance failure has significant business impact
* Event duration 2-3 days with continuous merchandise flow
* New merchandise types not previously validated

Technical Req:

* Custom tag specifications requiring expert printer calibration
* Multiple tag types needed for different merchandise categories


Decision Rule: If 3 or more criteria are met, on-site printing is required.



Tier 2: Standard Pop-Ups

* Part-time oversight (setup + periodic check-ins)
* Merchant handles day-to-day with Amazonian support
* Remote monitoring via digital checklist and EPC scans

Inventory Predictability:

* Final SKU list available +1 week before event
* Merchandise quantities confirmed with <10% variance expected (risk of low tags accepted)
* Merchandise delivery consistent daily
* No replenishment expected during event

Operational Capacity:

* Adequate BOH space for pre-tagged merchandise storage
* Merchant has overhead to receive and apply pre-printed tags
* Stable staff (full-time or well-trained associates)
* Organized pre-launch environment with tagging as priority

Event Characteristics:

* Repeat venue with established/known processes
* Standard merchandise types (apparel, accessories, beverages)
* Event duration 1 week+ allowing time for corrections
* Previously validated merchandise-tag combinations
* Lower business impact if minor issues occur

Technical Simplicity:

* All UPCs available in system for pre-printing
* Standard tag types from validated catalog
* Single tag type covers all merchandise
* Merchant can apply tags following SOP and/or virtual training

Risk Mitigation:

* Buffer time (24-48 hours) before event for corrections
* Backup tags available if issues arise
* Non-customer-facing location during setup
* Amazonian available for remote troubleshooting

Decision Rule: If 5 or more criteria are met




Tier 3: Routine/Repeat Pop-Ups

* 3P Vendor with self-service checklist
* Amazonian reviews documentation pre and post event
* Escalation support available if needed w/SMEs
